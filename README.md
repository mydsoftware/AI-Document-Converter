# مبدل هوشمند همه‌کاره

**AI Document Converter** یک هسته ماژولار برای تبدیل و پردازش هوشمند اسناد، تصاویر، صوت و ویدیو است.

## هدف پروژه

ساخت یک ابزار قابل اجرا روی ویندوز که نوع فایل را تشخیص دهد، بهترین مسیر پردازش را انتخاب کند و در صورت نیاز از OCR، هوش مصنوعی محلی و موتورهای تبدیل استفاده کند؛ بدون اجبار به API پولی.

## قابلیت‌ها

- معماری کاملاً ماژولار و افزونه‌پذیر
- تشخیص خودکار نوع فایل
- PDF متنی و اسکن‌شده
- OCR فارسی و انگلیسی
- پردازش مستقل هر صفحه PDF
- تشخیص اولیه چاپی/دست‌نویس
- موتور HTR مبتنی بر Transformer به‌صورت Backend قابل تعویض
- انتخاب مدل AI و HTR بر اساس RAM، GPU و VRAM
- اجرای مدل محلی با Ollama
- API سازگار با OpenAI به‌صورت اختیاری
- تبدیل ساختاریافته به Word
- زیرساخت صوت و ویدیو با FFmpeg
- CLI ویندوز
- آزمون خودکار و GitHub Actions

## نمونه Pipelineها

```text
PDF → تشخیص صفحه → OCR/HTR → هوش مصنوعی → Word
تصویر → تشخیص چاپی/دست‌خط → OCR/HTR → هوش مصنوعی → Word
ویدیو → استخراج صوت/فریم → گفتار/تصویر → تحلیل AI → خروجی
```

## هوش مصنوعی بدون API

استفاده از API اجباری نیست. در حالت محلی، برنامه می‌تواند از Ollama استفاده کند و مدل مناسب را با توجه به توان سخت‌افزار کاربر انتخاب کند.

APIهای سازگار با OpenAI فقط یک گزینه اختیاری هستند.

## اجرا در ویندوز

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

بررسی سیستم:

```powershell
adc system --ai
```

تبدیل PDF به Word:

```powershell
adc convert document.pdf --to docx
```

## آزمون‌ها

```powershell
pytest
```

هسته ماژولار، تشخیص ورودی، انتخاب هوشمند مدل، OCR تصویر/PDF، مسیر دست‌خط، تولید Word و زیرساخت ویدیو در پروژه قرار گرفته‌اند. مدل تخصصی دست‌خط فارسی قبل از تبدیل‌شدن به مدل پیش‌فرض باید از نظر کیفیت، منابع و مجوز اعتبارسنجی شود.
