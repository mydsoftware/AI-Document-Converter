# مبدل هوشمند همه‌کاره

**AI Document Converter** یک هسته ماژولار برای تبدیل و پردازش هوشمند اسناد، تصاویر، صوت و ویدیو است.

هدف پروژه ساخت یک ابزار قابل اجرا روی ویندوز است که بتواند انواع فایل‌ها را تشخیص دهد، ماژول مناسب را انتخاب کند و در صورت نیاز چند تبدیل را به‌صورت زنجیره‌ای اجرا کند.

## قابلیت‌های معماری

- معماری کاملاً ماژولار و افزونه‌پذیر
- تشخیص خودکار نوع فایل
- اجرای زنجیره‌ای تبدیل‌ها با Pipeline
- قرارداد مستقل برای ماژول‌های تبدیل
- لایه مستقل هوش مصنوعی
- آماده برای OCR، تشخیص دست‌خط و گفتار به متن
- آماده برای پردازش ویدیو و صوت با موتورهایی مانند FFmpeg
- رابط خط فرمان ویندوز
- آزمون‌های خودکار
- GitHub Actions برای کنترل کیفیت و تست

## نمونه Pipelineها

```text
PDF → OCR → هوش مصنوعی → Word
ویدیو → صوت → گفتار به متن → زیرنویس
تصویر → OCR → هوش مصنوعی → Word
```

## وضعیت فعلی

نسخه فعلی، هسته واقعی پروژه شامل قرارداد ماژول‌ها، ثبت ماژول‌ها، تشخیص نوع فایل، Pipeline و CLI را فراهم می‌کند. اتصال موتورهای سنگین مانند OCR، FFmpeg و مدل‌های هوش مصنوعی در مراحل بعدی به‌صورت ماژول مستقل انجام خواهد شد.

## نصب توسعه

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

```powershell

```

```powershell

```

```powershell
pytest
```

## افزودن ماژول جدید

هر ماژول باید قرارداد `ConverterModule` را پیاده‌سازی کند، ورودی و خروجی‌های خود را اعلام کند و در ثبت‌کننده ماژول‌ها ثبت شود. هسته نباید به پیاده‌سازی داخلی ماژول وابسته باشد.
