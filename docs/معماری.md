# معماری پروژه

## اصل اصلی

هسته پروژه فقط مسئول هماهنگی است. منطق تبدیل در ماژول‌های مستقل قرار می‌گیرد.

## لایه‌ها

### هسته

شامل قراردادها، مدل‌های داده، تشخیص فایل، ثبت ماژول و Pipeline است.

### ماژول‌ها

هر قابلیت در یک ماژول مستقل قرار می‌گیرد. نمونه‌های آینده:

- PDF
- Word
- Excel
- PowerPoint
- تصویر
- OCR
- دست‌خط
- صوت
- ویدیو
- زیرنویس
- فشرده‌سازی

### ارائه

CLI فعلی اولین لایه ارائه است. در آینده GUI، API و وب‌اپلیکیشن می‌توانند از همان هسته استفاده کنند.

### موتورهای خارجی

FFmpeg، موتور OCR، مدل گفتار به متن و مدل‌های هوش مصنوعی نباید مستقیماً به هسته وابسته شوند. برای آنها قرارداد یا Adapter مستقل ساخته می‌شود.

## Pipeline

Pipeline اجازه می‌دهد خروجی یک ماژول ورودی ماژول بعدی شود. بنابراین قابلیت‌های پیچیده بدون ایجاد یک مبدل غول‌پیکر ساخته می‌شوند.

مثال:

```text
ویدیو
  ↓
استخراج صوت
  ↓
گفتار به متن
  ↓
اصلاح هوشمند
  ↓
زیرنویس
```

## اصل توسعه

افزودن یک قابلیت جدید نباید نیازمند تغییر هسته باشد؛ فقط باید قرارداد مناسب پیاده‌سازی و ماژول ثبت شود.
